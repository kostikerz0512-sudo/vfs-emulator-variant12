# Эмулятор оболочки ОС с VFS (Вариант №12)

Программное решение практических заданий по дисциплине «Конфигурационное управление».
Эмулятор командной строки UNIX-подобной ОС с виртуальной файловой системой (VFS) в памяти.

## Возможности

- **Консольный интерфейс (CLI)** с приглашением `vfs_name:~$`.
- **Простой парсер** (разбиение по пробелам).
- **Параметры командной строки**:
  - `--vfs <путь>` — загрузка VFS из XML-файла в память.
  - `--script <путь>` — выполнение стартового скрипта при запуске.
- **Выполнение скриптов**: поддержка комментариев (`#`), остановка при первой ошибке.
- **`motd`**: при старте выводится сообщение из файла `motd`, если он есть в корне VFS.
- **Обработка ошибок**: файл не найден, неверный формат XML, неизвестная команда, неверные аргументы.

## Реализованные команды

- `ls [path]` — список файлов и папок.
- `cd <path>` — переход по директориям (поддержка `..`, `.`, абсолютных и относительных путей).
- `mkdir <name>` — создать директорию в текущей папке.
- `rm <path>` — удалить файл или директорию.
- `rev <text>` — перевернуть строку (символы).
- `tac <file>` — вывести файл построчно с конца.
- `whoami` — имя текущего пользователя (`root`).
- `echo <text>` — вывод аргументов.
- `help` — список команд с описанием.
- `exit` — выход из эмулятора.

## Формат VFS (XML)

Виртуальная ФС хранится в XML-файле и загружается в память (файл на диске не изменяется).
Пример (`vfs_data/deep.xml`):

```xml
<?xml version="1.0" encoding="UTF-8"?>
<fs>
    <file name="motd">Добро пожаловать в VFS-эмулятор!</file>
    <dir name="home">
        <dir name="user">
            <dir name="docs">
                <file name="notes.txt">My notes</file>
            </dir>
            <file name="readme.md"># Profile</file>
        </dir>
    </dir>
    <dir name="bin">
        <file name="sh">binary_data_here</file>
    </dir>
</fs>
